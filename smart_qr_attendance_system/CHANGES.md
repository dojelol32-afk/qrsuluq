# قائمة الإصلاحات

| المشكلة القديمة | الإصلاح |
|---|---|
| `session_id`/`student_id` من نوع UUID بينما الواجهة ترسل `cs101` و`4423` | الطالب يدخل بحسابه والسيرفر يأخذ `student_id` من الـ JWT، و`session_id` يأتي من الـ QR |
| `index.js` يكتب العمود `timestamp` والحالة `Present` | يكتب `marked_at` والحالات المسموحة `On_Time/Late/Very_Late` |
| تقرير CSV يطبع `r.student_id` غير المختار فيظهر `undefined` | الاستعلام يختار `student_number` من جدول المستخدمين |
| `index.js` لا يستورد `dotenv` | `config.js` يحمّل `.env` ويتحقق من المتغيرات المطلوبة عند الإقلاع |
| نسختان متعارضتان من الباكند | نسخة واحدة: `index.js` يربط كل الـ controllers |
| QR عشوائي داخل صفحة الطالب ولا يُتحقق منه | السيرفر يولّد TOTP ويعرضه المحاضر، والطالب يمسحه بالكاميرا |
| `/api/sessions/create` والتقرير بلا مصادقة | JWT + أدوار + فحص ملكية الجلسة |
| `JWT_SECRET` احتياطي ثابت | الإقلاع يفشل إن كان غير موجود أو أقصر من 32 حرفاً |
| CORS مفتوح `*` | قائمة أصول صريحة في الإنتاج |
| حظر IP يمنع طلاب نفس شبكة الجامعة | أُزيل الحظر، يُخزّن الـ IP للمرجعية فقط |
| حقن الصيغ في CSV | `csvEscape` يعالج `= + - @` ويضاعف علامات الاقتباس |
| لا حد للمحاولات | `express-rate-limit` على الدخول والمسح والطلبات العامة |
| السر يُرسل من المتصفح عند إنشاء الجلسة | السر يُولَّد في السيرفر ولا يُعاد للعميل أبداً |
| `schema.sql` بلا كلمات مرور أو رقم طالب | أعمدة `password_hash` و`student_number` و`title` وفهارس وسحب صلاحيات `anon` |
